# Development scripts

Skeleton Phase 0; chưa có automation hoặc app launch script.

Script sẽ được thêm khi có tác vụ thực tế: kiểm tra toolchain/build ở Phase 1, chạy backend ở Phase 2, hạ tầng/migration/backup ở Phase 6. Mỗi script phải ghi phụ thuộc, working directory, tác động và exit code; thao tác file giới hạn trong project hoặc thư mục người dùng chọn.

Kiểm tra hồ sơ hiện tại dùng Python standard library và Git như mô tả trong [development guide](../docs/development-guide.md) và [verification](../docs/phase-0-verification.md). Không cần cài dependency để đọc hoặc kiểm tra skeleton.
