# Applications

Skeleton Phase 0; chưa có executable, dependency manifest hoặc lệnh chạy app.

- [desktop](desktop/README.md): Tauri + React + TypeScript; triển khai sau khi duyệt Phase 1.
- [backend](backend/README.md): FastAPI modular monolith; bắt đầu Phase 2.

Desktop và backend là hai tiến trình cùng sản phẩm. Nghiệp vụ backend chưa được tách thành microservices. Xem [architecture](../docs/architecture.md).
